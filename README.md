# Maloka

**Website Informasi Wisata dan Travel Agent Magelang**

Maloka merupakan platform digital yang menyediakan informasi destinasi wisata di Magelang sekaligus membantu wisatawan dalam merencanakan dan memesan kebutuhan perjalanan dalam satu tempat.

## About Project

Website ini dikembangkan sebagai project mata kuliah **Pemrograman Web Framework**.

Maloka dirancang untuk menyediakan informasi wisata yang terstruktur serta layanan travel agent seperti pemesanan tiket wisata, tour guide, penginapan, dan transportasi.

## Main Features

* Landing Page
* Informasi Wisata
* Kategori Wisata
* Pencarian Wisata
* Travel Agent / Pemesanan
* Login Admin
* Dashboard Admin
* AI Budgeting
* Review & Rating
* Online Payment

> Beberapa fitur seperti AI Budgeting, Review & Rating, dan Online Payment direncanakan sebagai pengembangan lanjutan di luar MVP.
